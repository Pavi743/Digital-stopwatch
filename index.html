Theory & Requirements

Real-World Problem & Objective

A stopwatch requires accurate measurement of elapsed time. Digital systems achieve this using clock pulses, sequential state control and counters.

⚠️ The Problem

Manual timing introduces human reaction latency and arbitrary timing drifts. Furthermore, asynchronous or software-loop timers suffer from accumulation jitter and lack predictable cycle synchronization.

💡 The Solution

A digital stopwatch based on synchronous sequential logic updates its state and counters at defined clock edges, preventing timing races, eliminating glitches, and ensuring deterministic temporal resolution.

🎯 Laboratory Objectives

Design and simulate a digital stopwatch system featuring:

  • START Control
  • STOP Control
  • RESET Control
  • Master Clock
  • MOD-60 Counters
  • 7-Segment Display

Engineering Specifications

Design Assumptions

Key operational assumptions governing this sequential digital electronics simulation.

  • 1. Default Clock Frequency: Configured at 1 Hz for real-time 1-second pulse increments.
  • 2. Software-Generated Clock: Synthesized square oscillator modeling discrete 50% duty cycle logic levels.
  • 3. Edge Triggering: State transitions and counter increments occur strictly on the active rising clock edge (0 ➔ 1).
  • 4. Seconds Counter Modulus: MOD-60 counter cycling through states 00 to 59.
  • 5. Minutes Counter Modulus: MOD-60 counter cycling through states 00 to 59.
  • 6. START Logic: Asserts asynchronous start pulse enabling the FSM to transition from IDLE/STOPPED to RUNNING at the next clock edge.
  • 7. STOP Logic: Transitions FSM from RUNNING to STOPPED, disabling the counter clock enable line.
  • 8. RESET Logic: Synchronous master clear returning all state flip-flops and counter registers to zero.
  • 9. Stopwatch Display Format: Standard MM:SS two-digit decimal representation with BCD decoding.
Software Engineering

Digital Circuit Simulation Architecture

Pure modular object-oriented ES6+ classes mapping directly to digital logic laboratory hardware blocks.

To mirror actual physical IC implementation, the project avoids standard single-line JavaScript timer shortcuts like setInterval(() => seconds++, 1000). Instead, it simulates discrete circuit blocks:

ClockEngine

Oscillator generating continuous square waves with edge-detection hooks (onRisingEdge).

StateRegister

Simulates physical D flip-flop storage cells Q1 (MSB) and Q0 (LSB) with synchronous clock gating.

StateMachine

Evaluates boolean next-state excitation equations: D1 and D0 from inputs and current register bits.

ModCounter

Synchronous MOD-60 counters with terminal count carry outputs cascaded to the minutes stage.

TimingCanvas

Logic analyzer visualizing multi-channel square waveforms for clock, control lines, and data bus.

TestRunner

Headless verification framework executing 15 unit tests against the logic modules without mocking passes.
